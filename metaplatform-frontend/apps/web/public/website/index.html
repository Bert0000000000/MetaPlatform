03 · 订单场景

从一笔订单开始

1.1 首条验收场景：把订单和客户数据变成关联对象，在订单审核应用中查看订单，人工确认后执行动作并查看回执。

  1. 接入与建模

    PostgreSQL / CSV → 字段预检 → 订单与客户对象、关联关系。

  2. 发布与运行

    校验模型 → 绑定订单审核模板 → 发布应用 → 查看同一笔订单。

  3. 确认与追溯

    预览动作 → 人工确认 → 执行回执 → 版本、审计与恢复证据。

该完整业务链为 1.1 验证目标，尚未作为产品发布验收承诺。

05 · 常见问题

开始之前

官网需要登录吗？

官网公开可读。点击“进入平台”打开工作区，未登录访问者进入现有登录流程。业务 API 继续使用平台认证。

业务对象和数据表有什么区别？

数据表保存技术字段；业务对象用订单、客户等业务概念描述属性、关联与动作。模型映射把两者连接，应用引用这些业务语义。

Agent 可以直接替我执行所有动作吗？

Agent 的工具调用受租户、身份和授权限制。需要确认的动作遵循平台 Proposal 预览、人工确认与执行流程；新客户端兼容仍需验证。

现在可以试用什么？

使用已有平台账号进入工作区查看获授权的功能。功能可用性依赖部署、数据源和工作区权限。尚未验收的 1.1 链路和未来客户端接入已明确标注。
