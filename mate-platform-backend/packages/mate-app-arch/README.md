# mate-app-arch

Mate Platform - APP-ARCH architecture center.

27 GET endpoints under `/api/v1/arch/*` (FR-ARCH-001..027)
covering applications, business processes, capabilities, data
assets / entities / flows / standards / domains, deployments /
infrastructures, governance (principles, review templates,
review tickets, tech debts), impact analysis, ontology mappings,
orgs / roles, tech stacks, technology components / radar / stacks,
and value streams.

Data sources are in-memory for the P2-W2 batch; persistent
storage (Paimon / Postgres / Iceberg) lands in v3.2.
