# 候选关系可操作性修复：本地验收

日期：2026-10-11。依据：[实施说明](../superpowers/plans/2026-10-11-relationship-readiness.md)、[ADR-0083](../active/decisions/ADR-0083-data-driven-modeling-phase1.md)。

## 行为

- 审核页提前统计关联字段不完整的关系，并直接进入首条关系处理。
- 关系详情显示中文目标身份、缺失字段、关联证据与实际映射的区别；精确同 ID 或同名、同类型且无歧义的属性提供待确认映射建议。
- 点击采用才修改草稿。不会自动确认基数、唯一性或发布；部分映射仍不能通过完整身份校验。
- 可直接打开目标对象配置替代唯一键，或暂不发布当前关系。暂缓保留定义，不影响其他候选。
- 空关联及未选择的条件允许保存为待完善草稿，但无法审核、发布或同步。字段下拉框显示明确的未选择提示。
- 历史已接受但当前规则不完整的关系，不显示为已确认，也不计入批量审核通过数量。
- AI 提示强调来源列证据不是 joins。生成完成后进行确定性字段预检，缺失项保留未批准状态并写入容量受限的待完善说明。

## 证据

- 后端规则、生成适配、结构及发布范围回归：170 项通过。
- 独立 PostgreSQL 数据库 `modeling_sync_20261011` 集成：27 项通过，包括保存空关系、刷新恢复、校验拦截及暂缓后其他类型可发布；未跳过。
- 前端完整 from-data 定向回归：48 项通过；类型检查与生产构建通过。
- Edge 浏览器使用独立模拟来源验证采用建议、部分身份仍被拦截、目标编辑导航、暂缓保留定义；本体 API 写请求为 0。桌面 1441px、窄屏 390px 已视觉核对。
- OpenAPI YAML 可解析；候选 `joins` 可为空，空选择与运行时声明一致；发布限制由校验执行。

本地证据位于忽略目录 `.cache/local-runtime/`：`relationship-tests.json`、`sync-integration.xml`、`check-relationship-repair.cjs`、`relationship-repair-desktop.png`、`relationship-repair-mobile.png`。

用户业务来源和本体未被测试修改。本体服务 8207 和建模服务 8701 已在确认无运行任务后重启；OpenAPI 可读。没有自动重新生成用户候选。

此功能不能替代业务定义或补造缺失字段；不把样本无重复认定为业务唯一，也不承诺缺少原始字段的关系能自动修复。数据值、唯一性及匹配结果继续由既有数据校验和同步检查执行。本记录为本地工程验收，CI 和业务验收另行登记。
