## Findings addressed

- New modeling operations lacked contract metadata and requirement-matrix entries.
  Mutation and AI operations inherited `platform.read`; they now declare `platform.write`.
- Duplicate operation descriptions hid the detailed generation limits, and the SSE
  description was placed outside its schema. Both YAML issues are corrected.
- ONT's Docker image and minimal CI test environment omitted `openpyxl` and
  `python-multipart`, causing ONT startup and test collection to fail.
- Generated platform and bundled contracts were stale. Both are regenerated from
  the canonical service contracts, without bypassing contract drift checks.
- Spectral's inherited duplicate-enum selector crashes on valid null defaults.
  A null-safe selector retains the same enum uniqueness validation and severity.
- Python lint and formatting errors are corrected using the repository's Ruff version.
- Modeling HTTP calls now use the existing OpenAI provider adapter for vendor
  credentials, and the shared user-delegation ACL for internal calls. Regression
  probes verify tenant/user header binding and connection cleanup on stream failure.
- ONT's image fallback and compose import path now include the shared client ACL.
  Excel staging requires an explicit reader DSN pointing to the active kernel
  database. CI provisions a read-only NOSUPERUSER NOBYPASSRLS reader for that
  database, including SELECT grants on newly created staging tables.
- The mobile keyboard navigation test now follows the new modeling entry before
  reaching relationship types. All seven modeling browser cases now execute in
  the required ontology-core job, including repeat sync and identity repair.
- The dev realm's backend client now emits users' existing realm roles into its
  access token. The browser gate verifies a real administrator can write while
  a normal user remains denied; no user role assignments are expanded.
- Modeling's browser config owns an ephemeral CI web server, matching the other
  suites, while local runs preserve any externally owned preview.
- Browser actions now exercise the current review tabs/detail sheets and the
  mandatory sync-check/confirmation flow. Native-definition, identity, instance
  count and repeat-sync assertions are retained after the UI refactor.
- The 34 modeling PostgreSQL cases previously skipped in CI. They now execute in
  the existing isolated nonprivileged PostgreSQL job, with a no-skip result check.
  The 58 modeling frontend cases are added to the required frontend check.
