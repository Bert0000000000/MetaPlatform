## 1. 「注册工具」按钮（FR-MCPHUB-3.2）

**触发位置**：工具注册中心 `/mcp/tools` 右上角「注册工具」主按钮。

**操作流程**：

1. 用户点击「注册工具」 → 系统弹出"注册工具"向导对话框（共 4 步）
2. **第 1 步：基本信息**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|---------|------|
| 工具名称 | String[a-zA-Z0-9_-]{3,50} | 是 | 全平台唯一；不可包含空格 | 内部标识 |
| 显示名 | String(2-30) | 是 | - | 中文展示名 |
| 工具分类 | Enum | 是 | 业务工具/数据工具/系统工具/AI 工具 | 用于分组 |
| 工具描述 | Text(10-500) | 是 | 至少 10 字 | 用于语义检索 |
| 版本 | String | 是 | 默认 `1.0.0` | semver |

3. **第 2 步：定义 Schema**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|---------|------|
| 输入参数 | JSON Schema | 是 | 必填完整 type 字段 | 见示例 |
| 输出格式 | JSON Schema | 是 | - | 返回结构定义 |
| 错误码定义 | Array | 否 | 1000-9999 范围 | 标准错误码 |

4. **第 3 步：关联 Server**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 所属 Server | Ref | 是 | 关联已注册的 Server |
| 协议版本 | Enum | 是 | MCP 2024-11 / 2025-03 |
| 传输方式 | Enum | 是 | stdio / SSE / Streamable HTTP |

5. **第 4 步：测试与发布**

| 操作 | 说明 |
|------|------|
| 单元测试 | 用户填写测试输入 → 系统模拟执行 → 返回示例输出 |
| 试运行 | 在沙箱环境真实调用一次 |
| 灰度发布 | 先 10% 流量 → 监控 → 全量 |

6. 用户点击「完成注册」 → 工具注册到 Nacos 3.0+ → Server 自动更新暴露列表

## 2. 「创建 Server」按钮（FR-MCPHUB-3.1.2）

**触发位置**：Server 管理 `/mcp/server` 右上角「创建 Server」。

**操作流程**：

1. 用户点击「创建 Server」 → 弹出"创建 MCP Server"对话框
2. 用户填写以下表单：

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|---------|------|
| Server 名称 | String[a-z0-9-]{3,30} | 是 | 全平台唯一；小写连字符 | 内部标识 |
| 显示名 | String(2-30) | 是 | - | 中文展示名 |
| 协议版本 | Enum | 是 | MCP 2024-11 / 2025-03 | 默认 2025-03 |
| 传输方式 | Multi | 是 | stdio + SSE / stdio + HTTP / SSE only | 多选 |
| Endpoint | String(URL) | 条件 | 传输含 HTTP 时必填 | SSE/HTTP 端点 |
| Stdio 命令 | String | 条件 | 传输含 stdio 时必填 | 可执行命令 |
| 描述 | Text(0-500) | 否 | - | 业务说明 |
| 标签 | Array[String] | 否 | 最多 5 个 | 用于检索 |
| 健康检查 | Boolean | 是 | 默认开启 | Nacos 主动探活 |

3. 用户点击「确认创建」 → Server 注册到 Nacos 3.0+ → 自动生成 Agent Card 骨架
4. 用户继续添加 Tools / Resources / Prompts（在 §3 详情页操作）

## 3. 「配置暴露的 Tools/Resources/Prompts」按钮（FR-MCPHUB-3.1.3）

**触发位置**：Server 详情页 → 「暴露配置」标签页 → 三个 Tab（Tools/Resources/Prompts）。

### 3.1 添加 Tool

1. 用户点击「添加 Tool」 → 弹出"选择工具"对话框
2. 列表展示所有 `已注册但未关联本 Server` 的 Tool
3. 用户多选 Tool，点击「确认关联」
4. 写入 `server_tool_binding` 表

### 3.2 添加 Resource

1. 用户点击「添加 Resource」 → 弹出"添加 Resource"对话框：

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| URI | String[uri-pattern] | 是 | 唯一 |
| 名称 | String(2-30) | 是 | - |
| MIME Type | String | 是 | 标准 MIME |
| 描述 | Text | 否 | - |

2. 用户点击「确认」 → Resource 添加到 Server

### 3.3 添加 Prompt

1. 用户点击「添加 Prompt」 → 弹出"添加 Prompt 模板"对话框：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| Prompt 名称 | String[a-zA-Z0-9_-]{3,30} | 是 | 唯一 |
| 模板内容 | Text | 是 | 支持 {{变量}} 占位符 |
| 变量定义 | JSON | 条件 | 模板含变量时必填 |
| 参数说明 | Text | 否 | - |

2. 用户点击「确认」 → Prompt 添加

## 4. 「Server 启停」按钮（FR-MCPHUB-3.1.4）

**触发位置**：Server 详情页 → 头部「启动/停止」切换按钮。

**操作流程**：

1. 用户点击「停止」 → 弹出二次确认（停止后 30 秒内无调用才会完全下线）
2. 状态变化：

| 状态 | 含义 | 监控 |
|------|------|------|
| RUNNING | 正常运行 | 健康检查 + 调用统计 |
| STOPPING | 停止中 | 等待现有调用完成（≤ 30s） |
| STOPPED | 已停止 | 不接受新调用，Nacos 摘除 |
| FAILED | 启动失败 | 错误日志 + 重试按钮 |

3. 用户点击「启动」 → Nacos 重新注册 → 健康检查通过 → 状态变为 `RUNNING`
4. 启停过程全程记录审计日志

## 5. 「添加连接」按钮（FR-MCPHUB-3.2.2）

**触发位置**：MCP Client 管理 → 第三方 Server 连接列表 → 「添加连接」。

**操作流程**：

1. 用户点击「添加连接」 → 弹出"添加第三方 MCP Server"对话框
2. 用户填写：

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|---------|------|
| 连接名称 | String(2-30) | 是 | 唯一 | - |
| Server URL | URL | 是 | https://...；可达性测试 | 第三方端点 |
| 协议版本 | Enum | 是 | 自动协商 | - |
| 鉴权方式 | Enum | 是 | None / API Key / OAuth2 | - |
| API Key | String | 条件 | 鉴权=API Key 时必填 | 加密存储 |
| OAuth2 Scope | String | 条件 | 鉴权=OAuth2 时必填 | - |
| 同步间隔 | Integer(s) | 否 | 默认 300 | 工具发现周期 |
| 超时 | Integer(s) | 否 | 默认 30 | 单次调用超时 |

3. 用户点击「测试连接」 → 系统尝试调用 `tools/list` → 显示连接状态
4. 连接成功 → 用户点击「确认添加」 → 写入 `mcp_client` 表 → 触发工具自动发现

## 6. 「创建调试会话」按钮（FR-MCPHUB-3.4.1）

**触发位置**：调试器 `/mcp/debugger` → 「新建会话」。

**操作流程**：

1. 用户点击「新建会话」 → 弹出"选择工具"对话框
2. 用户选择：
   - 目标工具（从已注册 Tool 列表）
   - 关联 Server（可选，默认从 Tool 自动解析）
3. 用户点击「确认」 → 创建调试会话，状态变为 `READY`
4. 进入调试主界面（§7）

---

## 7. 「执行调用」按钮（FR-MCPHUB-3.4.3）

**触发位置**：调试器主界面右侧 → 「执行」按钮。

**操作流程**：

1. 用户在左侧"输入参数"区填写 JSON 参数（自动从 Tool Schema 生成表单）
2. 用户可选择：

| 配置 | 说明 |
|------|------|
| 模式 | 真实调用 / 沙箱模拟 |
| 超时 | 5-120s |
| 流式 | 是 / 否 |
| 上下文 | 用户上下文 JSON |

3. 用户点击「执行」 → 调用 Tool → 响应展示在右侧"输出"区
4. 失败时显示错误码 + 堆栈
5. 用户可点击「保存为用例」 → 写入 `tool_test_case` 表

---

## 8. 「创建权限规则」按钮（FR-MCPHUB-3.6.2）

**触发位置**：权限控制 `/mcp/permissions` → 「创建规则」。

**操作流程**：

1. 用户点击「创建规则」 → 弹出"权限规则"对话框
2. 用户选择规则类型：

| 类型 | 说明 |
|------|------|
| 用户-工具 | 限定用户可调用的工具 |
| 应用-工具 | 限定应用可调用的工具 |
| 角色-工具 | 按角色限制 |
| 速率限制 | 每用户/应用 QPS 上限 |

3. 用户填写规则字段（按类型不同）：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 规则名称 | String(2-50) | 是 | - |
| 优先级 | Integer(1-100) | 是 | 默认 50，数值越大优先级越高 |
| 主体 | Ref | 是 | 用户/应用/角色 |
| 工具范围 | Array[Ref] | 是 | 允许/禁止的工具列表 |
| 时间窗口 | Cron | 否 | 限定生效时段 |
| IP 白名单 | Array[String] | 否 | - |

4. 用户点击「确认」 → 规则写入 `permission_rule` 表 → Nacos Config 推送

---

## 9. 「创建告警规则」按钮（FR-MCPHUB-3.5.4）

**触发位置**：调用审计 → 告警规则 → 「新建规则」。

**操作流程**：

1. 用户点击「新建规则」 → 弹出"告警规则"对话框
2. 用户填写：

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| 规则名称 | String(2-50) | 是 | 唯一 |
| 监控指标 | Enum | 是 | 错误率/响应时间/QPS/Token 消耗 |
| 阈值条件 | JSON | 是 | {operator: ">", value: 0.05} |
| 持续时间 | Integer(s) | 是 | ≥ 60s |
| 通知渠道 | Multi | 是 | 邮件/IM/Webhook |
| 通知人 | Array[Ref] | 是 | - |

3. 用户点击「确认」 → 写入 `alert_rule` 表 → TECH-OBS 注册

## 10. 「IDE 配置生成」按钮（FR-MCPHUB-3.7.1）

**触发位置**：外部应用对接 → IDE 配置指引 → 「生成配置」。

**操作流程**：

1. 用户选择目标 IDE（Cursor/Claude/Codex）
2. 用户选择需要暴露的 Tools（多选）
3. 用户点击「生成配置」 → 系统生成 IDE 配置文件：

```json
// Cursor 示例
{
  "mcp": {
    "servers": [{
      "name": "mate-platform",
      "url": "https://mcp.example.com/api/v1/mcp/server/{serverId}/sse",
      "auth": {
        "type": "oauth2",
        "clientId": "cursor-mcp-client"
      }
    }]
  }
}
```

4. 用户可选择「下载配置文件」或「复制到剪贴板」
5. 同步生成对接步骤文档（含认证 Token 申请流程）

---

## 11. 「导出审计日志」按钮（FR-MCPHUB-3.5.2）

**触发位置**：调用审计 → 审计日志列表 → 「导出」。

**操作流程**：

1. 用户点击「导出」 → 弹出"导出"对话框
2. 用户选择：

| 选项 | 说明 |
|------|------|
| 格式 | CSV / Excel / JSON |
| 时间范围 | 默认近 7 天，可自定义 |
| 过滤条件 | 用户/工具/状态码 |
| 包含字段 | 默认全部，可勾选 |

3. 用户点击「确认导出」 → 异步生成 → 下载链接（链接 24h 有效）
