# Mate Platform 用户手册（P8.3）

## 1. SuperAI 入门

- 进入 APP-SUPERAI
- 选择 Fast Query 或 Deep Task
- 输入问题，AI 自动拉取 Ontology 上下文 + RAG 检索 + LLM 推理

## 2. 数字员工

- 进入 APP-DW
- 创建员工：选择技能 / 绑定知识库 / 配置 Action 权限
- 启用 / 调度：可定时触发 / 事件触发

## 3. Ontology 治理

- 进入 APP-ONTSTUDIO
- 定义 Concept / Object / Metric / Action
- 审核 Candidate Fact -> Commit / 回滚

## 4. 知识库

- 进入 APP-KB
- 上传文档 -> 切片 -> 向量化
- 检索测试：查看 Top-K Evidence
