## 任务 1 · 执行中的 run 可取消

**现状**：取消只针对**停在闸门**的 run；**执行中的 run 有请求在等它**，取消它需**图在节点边界自查**。

- 图在节点边界查取消标志 → 能停就停，落终态 `cancelled`
- **已完成节点不重跑**；在途工具调用允许跑完再停（不硬断）

**判据**：执行中取消 → 落终态且**不再推进**；幂等（重复取消不覆盖更早终态）；既有链路不回归。

## 任务 2 · 超时值持久化

**现状**：每轮超时值记在**进程内**，重启后回落 `MATE_AGENT_TEAM_RUN_TIMEOUT_SECONDS`。

改为**随 run 落库**（检查点或 PG），重启后仍按原值裁决。

**判据**：设一个**非默认**超时 → 重启服务 → **仍生效**。

## 任务 3 · 事件流尾随（长连接）

**现状**：**回放**已有步骤后收流，不尾随。

改为**回放 + 尾随**：连上先补历史，之后**新步骤即推送**，直到 run 终态才关流。

**判据**：起 run 后连上 SSE → 后续步骤**实时到达** → 终态后正常关闭（不挂死）。

## 任务 4 · 失败重试

- 失败节点的**重试策略**（次数 / 退避）
- **幂等边界**：已产生副作用的节点**不得盲目重跑**

**判据**：可重试的失败会重试并成功；**有副作用的节点不被重复执行（负例）**。
