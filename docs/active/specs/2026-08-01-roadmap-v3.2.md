# Mate Platform v3.2 路线规划

> 版本:v1.0 · 2026-08-01
> 关联:`2026-07-27-mate-platform-delivery-roadmap.md` v1.5 + `architecture-implementation.md` 附录 A(Data-Ready Baseline)
> 状态:**Active**(本规划作为 v3.1 → v3.2 路线)
> 修订人:需求层(TRAE)

---

## 1. 背景

v3.0 GA(2026-07-30)与 v3.1 增量 wave(2026-08-01)收口后,Mate Platform 达到:

- 17 / 17 域接入完成
- 1500+ tests pass
- §13 硬规则 1-13 闭环(G2/G3/G4/G7 已 Accepted)
- 业务深化(P3-W8/W9)推进 4 域真实业务逻辑

但仍有一些**未来能力**不在 v3.1 范围内,需要在 v3.2 推进。

---

## 2. v3.2 路线总览

```
v3.1 (已收口)
  ├── 17 域接入完成
  ├── G2/G3/G4/G7 Accepted
  └── TD-5/TD-6 收口

v3.2 (规划中)
  ├── G6 RLS 迁移(应用层 + 数据库层双重防护)
  ├── G8 旧 infra 清理(代码体积减小)
  ├── mcp federation 真实化(对接外部 MCP server)
  ├── llmgw 多模态(图像 / 语音 / 视频)
  ├── ont 推理(SHACL / OWL Reasoner)
  ├── 联邦查询 / 跨本体合并
  ├── 真实 Paimon / Iceberg / Trino 部署
  └── 多模态数据产品 / BI 集成
```

## 5. v3.2 优先级矩阵

按业务价值 / 工作量评估:

```
                  低工作量        高工作量
业务价值高        P1 立即做        P2 战略性投入
业务价值中        P3 必备          P4 后续考虑
业务价值低        P5 跳过          P6 跳过
```

| 任务 | 工作量 | 业务价值 | 优先级 |
|---|---|---|---|
| G6 RLS | 1-2 周 | 高 | **P1** |
| G8 旧 infra | 0.5 天 | 中 | **P3** |
| mcp federation | 1 周 | 高 | **P1** |
| llmgw 多模态 | 2-3 周 | 高 | **P2** |
| ont SHACL 推理 | 1-2 周 | 中 | **P3** |
| Paimon 真实部署 | 2 周 | 高 | **P2** |
| Iceberg 真实部署 | 2 周 | 高 | **P2** |
| Trino 真实部署 | 2 周 | 中 | **P2** |
| 数据产品发布 | 2 周 | 中 | **P4** |
| BI 集成 | 2 周 | 低 | **P5** |

## 7. v3.2 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 多模态 LLM 成本 | llmgw 多模态调用费用高 | 限流 + 计费 + 用户配额 |
| Iceberg / Trino 学习曲线 | 团队不熟 | 提前 spike + 官方文档 |

| G6 RLS 性能开销 | 单表查询慢 1-5ms | 在 tenant_id 列建覆盖索引;P95 < 10ms |
| 多模态数据产品 | 容量 / 成本 | 限流 + 配额 + 计费 |
