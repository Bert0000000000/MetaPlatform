AIP (Artificial Intelligence Platform) builds production-ready AI-powered workflows, agents, and functions on
top of the Ontology. AIP Chatbot Studio (formerly AIP Agent Studio) builds interactive assistants using the
Ontology SDK and platform APIs, grounded in the Ontology, documents, and custom context. Agent tools can
execute Ontology edits (run automatically or with user confirmation). Pro-code agents can read/write Ontology
data, build platform resources, and migrate legacy systems. Palantir MCP lets external AI IDEs and agents
connect to the platform and gain context on the Ontology and Foundry tools. AIP Logic is built on the same
security model governing the rest of the platform (user and function permissions).
