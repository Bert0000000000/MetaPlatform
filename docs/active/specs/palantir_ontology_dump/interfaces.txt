An interface is an Ontology type that describes the shape of an object type and its capabilities. Interfaces
provide object type polymorphism, allowing for consistent modeling of and interaction with object types that
share a common shape. An object type implements an interface by containing the interface's shared properties
or mapping existing object properties onto interface properties.
