An object type is the schema definition of a real-world entity or event; an object is a single instance of an object type.
Object types are defined by mapping existing datasources into objects, properties, and links in the Ontology.
Properties define characteristics of object types. Object types support mandatory control properties
(Markings, Organizations, Classifications) on the property level for security classification.
