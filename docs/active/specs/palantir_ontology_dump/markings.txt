Markings are a mandatory security control restricting resource access to only users satisfying ALL applied
Marking criteria. Mandatory controls restrict access by requiring a user to hold a particular Marking to
access data (managed via the Expand Access permission on the Marking itself). Markings propagate down data
lineage. Related mandatory control types on properties: Markings, Organizations, and Classifications
(classification-based access controls protect sensitive government information). Security combines mandatory
and discretionary controls which propagate.
