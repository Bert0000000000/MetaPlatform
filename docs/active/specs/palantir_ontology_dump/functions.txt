Functions provide first-class support for authoring logic based on the Ontology (reading object properties,
reusing logic across use cases). Functions on objects: native support for accessing and modifying data from
objects and links after defining object/link types. Object set APIs: filter object sets, perform Search
Arounsd via link types, compute aggregations. Manage published functions via Ontology Manager's Functions tab.
