An action type defines a set of changes or edits to objects, property values, and links that a user can take
at once, including side effects. Action types can be backed by functions (function-backed actions) or by
simple rules that create/modify/delete objects or links. Ontology edit functions must be configured as
Actions (function-backed Actions) to take effect.
