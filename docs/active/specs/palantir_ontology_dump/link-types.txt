A link type is the schema definition of a relationship between two object types; a link refers to a single
instance of that relationship. Cardinality: the Foundry Ontology supports 1-to-1, 1-to-many, and many-to-many
link types. When accessing the "1" side of a link, the generated field is a single object; on the "many" side,
a list/collection. Link types can be created from the link type graph on an object type's Overview page.
