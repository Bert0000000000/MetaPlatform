## 3. PG 真实服务接入

### 3.1 启真 PG（外部步骤）

```bash
docker run -d --name mate-postgres -p 5432:5432 \
  -e POSTGRES_USER=mate -e POSTGRES_PASSWORD=mate -e POSTGRES_DB=mate_kb \
  postgres:16-alpine
```

### 3.2 切 RAG_MODE=hybrid/full + PG_DSN

```bash
# 重 build RAG with env
docker run -d --name mate-tech-rag -p 8001:8001 \
  -e RAG_MODE=full \
  -e PG_DSN="postgresql://mate:mate@host.docker.internal:5432/mate_kb" \
  --network=mate-net \
  mate-tech-rag:dev
```
