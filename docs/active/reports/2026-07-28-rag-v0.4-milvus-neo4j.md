## 1. 本轮变更（v0.3 → v0.4）

### 1.1 真实客户端实现

| 客户端 | Protocol | 真实实现 | 依赖 |
|---|---|---|---|
| HybridClient (FACTUAL) | InMemoryHybridClient | **MilvusHybridClient** | pymilvus |
| GraphRAGClient (ENTITY) | InMemoryGraphRAGClient | **Neo4jGraphRAGClient** | neo4j-driver |
| LightRAGClient (THEMATIC) | InMemoryLightRAGClient | (placeholder) | httpx (待 TC-5.6.5) |
| RAGFlowClient (parse) | InMemoryRAGFlowClient | (placeholder) | httpx (待 TC-5.6.7) |

### 1.2 MilvusHybridClient 关键点

- 用 `pymilvus.MilvusClient` (轻量级，无需 standalone server)
- 启动时 `has_collection` → 没有则 `create_collection(dim, COSINE)`
- 字段：`id, document_id, text, embedding(FLOAT_VECTOR), metadata`
- 环境变量：`MILVUS_HOST, MILVUS_PORT, MILVUS_COLLECTION` (默认 mate_kb_chunks)
- 连接失败 → log warning + 降级到 InMemory（不 raise）

### 1.3 Neo4jGraphRAGClient 关键点

- 用 `neo4j.GraphDatabase` driver
- 数据库：`rag-graphrag`（per v3.0 Plan D）
- 启动时自动 `CREATE DATABASE IF NOT EXISTS` + `CREATE CONSTRAINT`
- 实体抽取：`re.compile(r"[\u4e00-\u9fff]{2,4}|[A-Z][A-Za-z0-9_]{2,}")`
- Cypher：`MERGE (c:Chunk)<-[:MENTIONED_IN]-(e:Entity)` + freq 计数
- 检索：`UNWIND $ents MATCH ... ORDER BY hits DESC, freq DESC`
- 连接失败 → log warning + 降级到 InMemory（不 raise）

### 1.4 create_clients 工厂

```python
def create_clients() -> None:
    mode = os.environ.get("RAG_MODE", "memory").lower()
    if mode in ("hybrid", "full"):
        try: _hybrid = MilvusHybridClient()
        except: _hybrid = InMemoryHybridClient()  # graceful fallback
    if mode in ("graph", "full"):
        try: _graph = Neo4jGraphRAGClient()
        except: _graph = InMemoryGraphRAGClient()
```

**RAG_MODE env**：
- `memory`（默认）：全 InMemory
- `hybrid`：用 Milvus
- `graph`：用 Neo4j
- `full`：两者都用

### 1.5 /status 动态 backend 标签

```
{"indexes": [
  {"name":"hybrid", "backend":"memory|milvus", "chunk_count":4},
  {"name":"graph", "backend":"memory|neo4j", "chunk_count":24},

```

`_backend_label(client)` 按类名自动判定（Milvus/Neo4j/LightRAG/默认 memory）。

## 3. 真实服务接入指南

### 3.1 启动 Milvus + Neo4j

```bash
docker run -d --name mate-milvus -p 19530:19530 milvusdb/milvus:v2.5.0
docker run -d --name mate-neo4j -p 7474:7474 -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/mate-pass neo4j:5.20-community
```

### 3.2 启动 mate-tech-rag 连真实服务

```bash
docker run -d --name mate-tech-rag -p 8001:8001 \
  -e RAG_MODE=full \
  -e MILVUS_HOST=host.docker.internal \
  -e MILVUS_PORT=19530 \
  -e NEO4J_URI=bolt://host.docker.internal:7687 \
  -e NEO4J_USER=neo4j \
  -e NEO4J_PASSWORD=mate-pass \
  --network=host \
  mate-tech-rag:dev

# /status 应显示：
# {"indexes": [
#   {"name":"hybrid", "backend":"milvus", "chunk_count":N},
#   {"name":"graph", "backend":"neo4j", "chunk_count":N},
#   ...
# ]}
```

### 3.3 当前限制

- RAGFlowClient / LightRAGClient 仍是 InMemory placeholder（未做 httpx 实现）
- Milvus Hybrid 仅做向量检索（BM25 融合留给 TC-5.6.4 完整版）
