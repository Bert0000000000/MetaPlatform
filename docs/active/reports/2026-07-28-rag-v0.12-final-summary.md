### 2.4 真实服务接入完整链路

```bash
# 启动全套（外部步骤）
docker run -d --name mate-postgres -p 5432:5432 -e POSTGRES_USER=mate -e POSTGRES_PASSWORD=mate -e POSTGRES_DB=mate_kb postgres:16-alpine
docker run -d --name mate-flowable -p 8080:8080 -e FLOWABLE_DATABASE_TYPE=h2 flowable/flowable-rest:6.8.0

# 一键启动 3 个 app 服务
docker compose -f docker-compose.yml -f docker-compose.mate-rag.yml up -d

# 验证
curl http://localhost:8001/healthz   # mate-tech-rag
curl http://localhost:8002/healthz   # mate-tech-agent
curl http://localhost:8003/healthz   # mate-app-kb
```

RAG_MODE env 控制：memory（默认离线）/ hybrid（+Milvus）/ graph（+Neo4j）/ full（两者）
EMBEDDER_PROVIDER env：local（默认离线）/ openai（+OPENAI_API_KEY）
LLM_PROVIDER env：echo（默认无 API）/ noop / openai
