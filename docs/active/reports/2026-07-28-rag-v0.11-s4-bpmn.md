## 1. 本轮变更

### 1.1 S4 graph（流程驱动）

```
[START] -> bpmn_deploy -> bpmn_start -> retrieve -> answer -> bpmn_monitor -> bpmn_complete -> persist -> [END]
```

每个节点的职责：
- **bpmn_deploy_node**：调 `Flowable.deploy_bpmn(process_key, bpmn_xml)` 上传 BPMN XML
- **bpmn_start_node**：调 `Flowable.start_process(process_key, variables)` 启动实例
- **bpmn_monitor_node**：调 `Flowable.get_process_state(instance_id)` 查状态
- **bpmn_complete_node**：标记 `process_status="completed"`
- **persist_node**：保存 state 到 JSON file

### 1.3 默认 BPMN XML（agent_qa）

```xml
<process id="agent_qa" name="Agent QA Process" isExecutable="true">
  <startEvent id="start"/>
  <sequenceFlow sourceRef="start" targetRef="retrieve"/>
```

## 3. 真实 Flowable 接入

### 3.1 启 Flowable（外部步骤）

```bash
docker run -d --name mate-flowable -p 8080:8080 \
  -e FLOWABLE_DATABASE_TYPE=h2 \
  flowable/flowable-rest:6.8.0

# 或 docker-compose
docker run -d --name mate-flowable -p 8080:8080 \
  -e SPRING_DATASOURCE_URL=jdbc:postgresql://mate-postgres:5432/flowable \
  -e SPRING_DATASOURCE_USERNAME=mate \
  -e SPRING_DATASOURCE_PASSWORD=mate \
  flowable/flowable-rest:6.8.0
```

### 3.2 切 agent 连 Flowable

```bash
docker run -d --name mate-tech-agent -p 8002:8002 \
  --network=mate-net \
  -e RAG_URL=http://mate-tech-rag:8001 \
  -e FLOWABLE_URL=http://host.docker.internal:8080 \
  mate-tech-agent:dev
```

`HttpxFlowableTool` 自动检测 /management/engine → `_available=True` → 真实调 Flowable REST API。
