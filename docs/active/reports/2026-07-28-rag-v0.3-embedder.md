## 1. 本轮变更（v0.2 → v0.3）

### 1.1 Embedder 重构（TC-5.6.2 落地）

`mate_tech_rag/embedder.py` 提供 3 个实现 + factory：

| Provider | Embedder | 维度 | 依赖 | 用例 |
|---|---|---|---|---|
| `openai` | OpenAIEmbedder | 1536 | `OPENAI_API_KEY` | 生产（真接入 OpenAI /v1/embeddings） |
| `local` (默认) | LocalTinyEmbedder | 384 | 无 | 离线 demo / 集成测试 |
| `hash` | HashEmbedder | 16 | 无 | legacy / 单元测试 |

**OpenAIEmbedder 关键点**：
- `httpx.Client` POST `/v1/embeddings`
- Auth: `Bearer ${OPENAI_API_KEY}`
- 默认模型 `text-embedding-3-small`（env `OPENAI_EMBED_MODEL` 可覆盖）
- `embed()` 单文本调用；`close()` 释放连接
- 缺 key 时 `raise ValueError("OpenAIEmbedder requires OPENAI_API_KEY")`

**LocalTinyEmbedder 关键点**：
- token-bag + 8 维 SHA-512 块 → 投影到 384 维
- L2 归一化
- 单元测试验证「相似文本 cosine > 不相关文本」

**factory**：`create_embedder(provider=None)` → 默认从 `EMBEDDER_PROVIDER` env 读

### 1.2 新增端点：`GET /api/v1/rag/status`

返回 embedder + 3 indexes 状态（用于监控 / 健康探针）：

```json
  "status": "ok",

  ]
}
```

## 5. OpenAI 接入说明

要切到 OpenAI 真实服务：

```bash
export OPENAI_API_KEY=sk-...
export OPENAI_EMBED_MODEL=text-embedding-3-small  # 可选
export EMBEDDER_PROVIDER=openai

docker run -d --name mate-tech-rag -p 8001:8001 \
  -e OPENAI_API_KEY=$OPENAI_API_KEY \
  -e EMBEDDER_PROVIDER=openai \
  mate-tech-rag:dev
```

容器启动会从 env 读 key，调用 `https://api.openai.com/v1/embeddings`。
缺 key 时启动失败 + 明确错误（避免静默回退到 local）。
