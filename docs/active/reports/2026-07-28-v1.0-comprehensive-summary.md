## 6. 真实服务接入

### 6.1 已实现客户端

| 客户端 | 实现 | 端点 | 容错 |
|---|---|---|---|
| MilvusHybridClient | pymilvus 真实 | has_collection + create + insert + search | 降级 to InMemory |
| Neo4jGraphRAGClient | neo4j driver 真实 | CREATE DATABASE + CONSTRAINT + MERGE | 降级 to InMemory |
| HttpxLightRAGClient | httpx to LightRAG | GET /health, POST /query | 降级 to InMemory |
| HttpxRAGFlowClient | httpx to ragflow | GET /api/v1/datasets, POST /chunks | 降级 fallback "原文当 chunk" |
| OpenAIEmbedder | httpx to OpenAI | POST /v1/embeddings | raise if no key |
| LocalTinyEmbedder | token-bag + hash | (offline) | default |
| RAGTool (agent) | httpx to mate-tech-rag | POST /api/v1/rag/search | return [] on fail |

### 6.2 切换方式

```bash
# RAG_MODE controls RAG clients
RAG_MODE=memory    # default: all InMemory
RAG_MODE=hybrid   # Milvus for hybrid, InMemory for others
RAG_MODE=graph     # Neo4j for graph, InMemory for others
RAG_MODE=full      # Milvus + Neo4j

# EMBEDDER_PROVIDER controls embedder
EMBEDDER_PROVIDER=local     # default: LocalTinyEmbedder (offline)
EMBEDDER_PROVIDER=openai    # OpenAI text-embedding-3-small (need OPENAI_API_KEY)
EMBEDDER_PROVIDER=hash      # legacy 16-dim

# LLM_PROVIDER controls LLM
LLM_PROVIDER=echo      # default: EchoLLM (no API)
LLM_PROVIDER=noop      # NoOpLLM (canned)
LLM_PROVIDER=openai    # ChatOpenAI (need OPENAI_API_KEY)

# URLs
RAG_URL=http://localhost:8001
AGENT_URL=http://localhost:8002
```

### 6.3 一键启动整套

```bash
# 启基础设施
docker compose -f docker-compose.yml -f docker-compose.mate-rag.yml up -d

# 三容器端到端
docker network create mate-net
docker run -d --name mate-tech-rag -p 8001:8001 mate-tech-rag:dev
docker run -d --name mate-tech-agent -p 8002:8002 \
  --network=mate-net -e RAG_URL=http://mate-tech-rag:8001 mate-tech-agent:dev
docker run -d --name mate-app-kb -p 8003:8003 \
  --network=mate-net -e RAG_URL=http://mate-tech-rag:8001 \
  -e AGENT_URL=http://mate-tech-agent:8002 mate-app-kb:dev
```
