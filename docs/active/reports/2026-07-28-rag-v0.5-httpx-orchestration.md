## 1. 本轮变更（v0.4 → v0.5）

### 1.1 新增 httpx 客户端

| 客户端 | 实现 | 真实端点 | 优雅降级 |
|---|---|---|---|
| **HttpxLightRAGClient** | HKUDS LightRAG | `GET /health`, `POST /query`, `POST /insert_text` | 不可达 → `_available=False` + 返回空 |
| **HttpxRAGFlowClient** | infiniflow/ragflow | `GET /api/v1/datasets`, `POST /api/v1/datasets/{id}/chunks` | 不可达 → fallback 为"原文当 chunk" |

### 1.2 新增编排文件

`docker-compose.mate-rag.yml`（与根 `docker-compose.yml` 配对使用）：

```yaml
services:
  neo4j:
    image: neo4j:5.20-community
    ports: ["7474:7474", "7687:7687"]
    environment: { NEO4J_AUTH: neo4j/mate-pass }
    healthcheck: { test: wget http://localhost:7474 }

  mate-tech-rag:
    image: mate-tech-rag:dev
    build: { context: ./mate-platform-backend, dockerfile: Dockerfile }
    environment:
      RAG_MODE: "full"
      EMBEDDER_PROVIDER: "local"
      MILVUS_HOST: "host.docker.internal"
      NEO4J_URI: "bolt://neo4j:7687"
    depends_on: { neo4j: { condition: service_healthy } }
    healthcheck: { test: curl http://localhost:8001/healthz }
```

**启动整套**：
```bash
docker compose -f docker-compose.yml -f docker-compose.mate-rag.yml up -d
```

### 1.3 4 个 RAG_MODE 行为（v0.5 完整支持）

| RAG_MODE | hybrid (FACTUAL) | graph (ENTITY) | lightrag (THEMATIC) | ragflow (parse) |
|---|---|---|---|---|
| `memory`（默认） | InMemoryHybridClient | InMemoryGraphRAGClient | InMemoryLightRAGClient | InMemoryRAGFlowClient |
| `hybrid` | **MilvusHybridClient** | InMemoryGraphRAGClient | **HttpxLightRAGClient** | **HttpxRAGFlowClient** |
| `graph` | InMemoryHybridClient | **Neo4jGraphRAGClient** | **HttpxLightRAGClient** | **HttpxRAGFlowClient** |
| `full` | **Milvus** | **Neo4j** | **HttpxLightRAG** | **HttpxRAGFlow** |

## 3. 编排文件 + 真实服务接入

### 3.1 一键启动整套

```bash
# 启动基础设施 + Neo4j + RAG 服务
docker compose -f docker-compose.yml -f docker-compose.mate-rag.yml up -d

# 验证
curl http://localhost:8001/api/v1/rag/status
# → indexes: hybrid=milvus, graph=neo4j, lightrag=lightrag-http, ragflow=ragflow-http
```

### 3.2 真实服务接入清单

| 服务 | 镜像 | 端口 | env vars |
|---|---|---|---|
| Milvus | `milvusdb/milvus:v2.5.0` | 19530 | MILVUS_HOST, MILVUS_PORT |
| Neo4j | `neo4j:5.20-community` | 7687 | NEO4J_URI, NEO4J_USER, NEO4J_PASSWORD |
| LightRAG | `hkuds/lightrag:latest` | 9621 | LIGHTRAG_URL, LIGHTRAG_API_KEY |
| RAGFlow | `infiniflow/ragflow:v0.13` | 9380 | RAGFLOW_URL, RAGFLOW_API_KEY |
| OpenAI | (外部) | — | OPENAI_API_KEY, OPENAI_EMBED_MODEL |
| OpenAI Embedder | — | — | EMBEDDER_PROVIDER=openai |

### 3.3 当前默认行为

- RAG_MODE 默认 `memory`：所有 client 用 InMemory（offline-safe）
- EMBEDDER_PROVIDER 默认 `local`：384 维 LocalTinyEmbedder（offline-safe）
- 要切到真实服务：设 `RAG_MODE=full` + 启 Milvus/Neo4j/LightRAG/RAGFlow 容器
