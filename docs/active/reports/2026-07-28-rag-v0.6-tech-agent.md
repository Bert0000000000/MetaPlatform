### 1.2 S1 场景：单 Agent QA

```
[START] -> retrieve_node (RAG search) -> answer_node (extractive synthesis) -> [END]

retrieve_node:
  1. 提取 user message
  2. 启发式 mode 判定：PascalCase -> ENTITY, else FACTUAL
  3. 调 RAGTool.search(query, top_k=5, mode)
  4. 存 retrieved_chunks + tool_calls

answer_node:
  - 无 chunks: "I could not find..."
  - 有 chunks: 取 top-3 snippets + count 拼成 answer
```

4. AUTO mode 启发式简单：PascalCase → ENTITY，否则 FACTUAL
5. 无 token 用量统计 / 成本控制
