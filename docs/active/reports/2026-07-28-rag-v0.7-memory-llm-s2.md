### 1.2 memory.py 关键点

```python
def save_state(thread_id, state):
    """Persist state dict to JSON file (best-effort, non-blocking)."""
    payload = {"_saved_at": time.time(), "state": state}
    p = _path_for(thread_id)
    p.write_text(json.dumps(payload, default=str, ensure_ascii=False), encoding="utf-8")
```

- Default: `AGENT_STATE_DIR=/tmp/mate_agent_state`
- Thread-safe via `threading.Lock`
- Path 净化（防 `..` traversal）
- Real: `langgraph-checkpoint-postgres` 当 `DATABASE_URL` 配 (TC-5.7.4 完整版)

    if provider == "noop":

### 1.4 S2 场景：多 Agent 协作

```
[START] -> planner -> worker -> synthesizer -> persist -> [END]

planner_node:
  decompose user query into 3 sub-questions:
    "{query} (overview)"
    "{query} (technical details)"
    "{query} (examples)"

worker_node:
  for each sub_question:
    detect mode (PascalCase → ENTITY, else FACTUAL)
    call RAGTool.search(q, top_k=3, mode)
  dedupe chunks by chunk_id
  return top-10 unique chunks

synthesizer_node:
  reuse answer_node (LLM synthesis with context)

persist_node:
  save_state(thread_id, state)
```

## 5. 已知限制

1. State 持久化用 JSON file，不是 Postgres（TC-5.7.4 完整版需 PostgresSaver）
2. S2 worker 实际效果依赖 RAG 端 chunk 命中（query "Tell me about MatePlatform" 0 hits 是因为 RAG 端 sample-doc 不含 "MatePlatform" ENTITY token 实际有，但 entity 抽取器对长 token "MatePlatform" 提取不完整）
3. LLM 默认 EchoLLM（不调 API），用 LLM_PROVIDER=openai 切真接入（需 OPENAI_API_KEY）
4. S3 HITL / S4 BPMN 场景未实现（501）
