## 1. 本轮变更（v0.1 → v0.2）

### 1.1 架构对齐
用户提醒后，把 mate-tech-rag 从"单路相似度"重构为 **v3.0 Plan D 的 4-component 架构**：

```
                ┌─── RAGFlow（DeepDoc 解析）───┐
                │  parse(content) -> chunks   │
                └────┬─────┬─────┬────────────┘
                     │     │     │
              ┌──────▼─┐ ┌─▼───┐ ┌▼────────┐
              │Hybrid  │ │Graph│ │LightRAG│
              │(FACTUAL│ │RAG  │ │(THEMA-│
              │ vector │ │(ENTI│ │ TIC)   │
              │+ BM25) │ │TY)  │ │        │
              └────┬───┘ └─┬───┘ └───┬────┘
                   └──────┬┴───────┘
                  Retrieval Router
                  AUTO / FACTUAL / ENTITY / THEMATIC
```

### 1.2 新增文件

| 路径 | 角色 |
|---|---|
| `packages/mate-tech-rag/src/mate_tech_rag/router.py` | 4-mode router + AUTO heuristic |
| `packages/mate-tech-rag/src/mate_tech_rag/strategies/base.py` | HybridStrategy / GraphStrategy / ThematicStrategy |
| `packages/mate-tech-rag/src/mate_tech_rag/clients/ragflow_client.py` | RAGFlow ACL（DeepDoc 占位） |
| `packages/mate-tech-rag/src/mate_tech_rag/clients/hybrid_client.py` | Hybrid ACL（Milvus+BM25 占位） |

| `packages/mate-tech-rag/src/mate_tech_rag/api/ingest.py` | 3 索引 fan-out (bypass RAGFlow) |

## 5. 已知限制

1. **InMemory 占位**：4 个 ACL client 都是 InMemory 实现，进程重启数据丢失
2. **Hash Embedder**：16 维 SHA-256 哈希，质量不足以生产
3. **无 Milvus/Neo4j 真实接入**：需后续 docker-compose 加 v2.4.3-slim 服务
4. **FastAPI 装饰器 pyright 误报**：2 个 `reportUnusedFunction`（已在 baseline 接受）
