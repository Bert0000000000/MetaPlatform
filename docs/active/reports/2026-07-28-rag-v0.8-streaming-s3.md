## 1. 本轮变更（v0.7 → v0.8）

### 1.1 LLM Streaming（TC-5.7.9）

**llm.py** 新增 `stream_answer()` 迭代器：
```python
def stream_answer(llm, query, chunks) -> Iterator[str]:
    prompt = _build_prompt(query, chunks)
    if hasattr(llm, "stream"):
        try:
            for token in llm.stream(prompt):
                yield token
            return
        except Exception:
            pass  # fall back
    full = synthesize_answer(llm, query, chunks)
    for word in full.split(" "):
        yield word + " "
```

- `EchoLLM` / `NoOpLLM` 都有 `.stream()` 方法（按 word 切分）
- `ChatOpenAI` 真接入自动用 LangChain astream
- 失败回退到 `synthesize_answer` 整块

### 1.2 S3 HITL（TC-5.7.7）

**S3 graph** 节点序列：
```
[START] → retrieve → answer → human_review → post_review → persist → [END]
```

- **human_review_node**：标记 `pending_review=True`，answer 前缀 `[AWAITING HUMAN REVIEW]`
- **post_review_node(approved=True)**：answer 追加 `[REVIEWED]` + feedback
- **post_review_node(approved=False)**：answer 追加 `[ABORTED]`

**chat 端点** S3 first call 用手动 invoke nodes（retrieve + answer + human_review），不调 post_review，实现"暂停"等评审。

### 1.3 /review 端点

```bash
POST /api/v1/agent/review
{
  "thread_id": "...",
  "approved": true,
  "feedback": "optional"
}
→ {
  "status": "approved" | "aborted" | "no_pending",
  "message": "<final answer with [REVIEWED]/[ABORTED] suffix>"
}
```
