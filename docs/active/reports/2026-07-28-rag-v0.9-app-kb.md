### 1.2 facade 设计

```
client -> mate-app-kb (8003)
              |-- httpx --> mate-tech-rag (8001)   /api/v1/rag/*
```

- **AgentClient** 封装 3 个 Agent 端点 + 1 个 SSE stream

## 5. 已知限制

1. **app-kb 是 thin facade**：只转发请求，没加业务逻辑（如权限、配额、路由策略）
2. **无 circuit breaker**：上游 RAG/Agent 挂掉会 502（但 graceful fail）
3. **无 response 缓存**：每次都重新调上游
4. **S4 BPMN 仍 501**（在 agent 端）
5. **thread_id 不在 app-kb 层管理**（透传给 agent）
