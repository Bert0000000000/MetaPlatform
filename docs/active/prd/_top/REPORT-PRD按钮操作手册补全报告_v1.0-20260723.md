# PRD 按钮操作手册补全报告

> **版本**: v1.0 | **日期**: 2026-07-23 | **执行者**: Claude PRD 刷新流程
>
> **触发原因**：用户反馈 PRD 文档中"新增"、"创建"、"编辑"等按钮未说明相关操作流程与需填写的内容。

---

## 1. 报告目的

针对 PRD 中"新增"、"创建"、"编辑"等按钮缺失操作流程与表单字段说明的问题，本报告系统盘点、补全并验证所有按钮的操作手册。每个按钮的操作手册包含：
- 触发位置
- 操作流程（含向导步骤）
- 表单字段（类型、必填、校验规则）
- 实时校验与结果反馈
- 失败处理

---

## 2. 补全策略

### 2.1 子文件拆分（避免主 PRD 膨胀）

为不影响主 PRD 文档结构（避免 AI 开发上下文过载），按钮操作手册**统一作为独立子文件**：

```
PRD-{模块名}-按钮操作手册_v1.0-20260723.md
```

### 2.2 统一章节结构

每个按钮的章节结构：

```
## N. 「按钮名」按钮（FR-XXX）

**触发位置**：UI 入口

**操作流程**：
1. 用户点击「按钮」 → 系统响应
2. 用户填写表单：
   | 字段 | 类型 | 必填 | 校验规则 | 说明 |
   |------|------|------|---------|------|
3. 用户点击「确认」 → 系统执行
4. 结果反馈
```

### 2.3 字段表统一规范

| 列 | 含义 |
|----|------|
| 字段 | 表单字段中文名 |
| 类型 | String/Integer/Enum/JSON/Array[Ref]/... |
| 必填 | 是 / 否 / 条件 |
| 校验规则 | 长度/正则/枚举值/唯一性/数值范围 |
| 说明 | 字段用途与填写提示 |

## 6. 子文件与主 PRD 的关系

所有按钮操作手册子文件**独立于主 PRD**，AI 开发时可按需加载：

```
场景：开发 APP-KB "创建知识库"功能
  → 加载 PRD-APP-KB-知识库-按钮操作手册_v1.0-20260723.md §1
  → 仅 1KB 上下文即可完成开发

场景：开发 APP-MCPHUB "Server 启停"
  → 加载 PRD-APP-MCPHUB-MCP服务中心-按钮操作手册_v1.0-20260723.md §4
  → 仅 1.5KB 上下文
```

**与主 PRD 的关系**：

- 主 PRD：定义功能、用户故事、API、数据模型（架构层面）
- 子文件：定义按钮操作流程、字段、校验（实现层面）
- 通过 Markdown 链接互通，互不重复

## 7. 后续维护

### 7.1 新增按钮时

新按钮的操作手册应：
1. 在对应模块的子文件中追加章节
2. 使用统一的章节结构与字段表规范
3. 标注关联 FR 编号

### 7.2 字段变更时

字段变更需同步更新：
1. 主 PRD 数据模型章节
2. 操作手册子文件对应章节

### 7.3 验收检查清单

每个新增/修改按钮必须满足：

- [ ] 触发位置明确（具体页面 + 区域）
- [ ] 操作流程分步骤编号
- [ ] 表单字段含类型/必填/校验规则
- [ ] 实时校验规则说明
- [ ] 失败处理说明
- [ ] 结果反馈说明（成功 + 失败）
- [ ] 关联 FR 编号标注
