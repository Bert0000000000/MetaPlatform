## 1. 「添加指标卡」按钮（FR-DASH-002-04）

**触发位置**：工作台编辑模式 → 「指标看板」 → 「添加指标卡」。

**操作流程**：

1. 用户点击「添加指标卡」 → 弹出"选择指标"对话框
2. 指标库列表（支持搜索）：

| 指标分类 | 示例 |
|---------|------|
| 平台指标 | 活跃用户、AI 调用次数、数字员工在线数 |
| 业务指标 | 今日订单、待审批数、流程完成率 |
| 自定义指标 | 用户配置（需填查询） |

3. 用户选择指标后，配置：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 卡类型 | Enum | 是 | 数字/进度条/折线图 |
| 标题 | String(2-20) | 是 | - |
| 副标题 | String | 否 | - |
| 刷新间隔 | Integer(s) | 否 | 默认 300 |
| 告警阈值 | JSON | 否 | {min, max} |
| 趋势对比 | Boolean | 否 | 与昨日对比 |

4. 用户点击「确认添加」 → 指标卡插入到工作台 → 实时刷新

## 2. 「添加快捷入口」按钮（FR-DASH-001-05）

**触发位置**：工作台 → 「快捷入口」区 → 「添加」。

**操作流程**：

1. 用户点击「添加」 → 弹出"选择应用"对话框
2. 列表展示可添加项：

| 类型 | 来源 |
|------|------|
| 应用 | APP-APPHUB 应用列表（按用户权限过滤） |
| 数字员工 | APP-DW 数字员工列表 |
| 外部链接 | 用户手动添加 |
| 收藏项 | 已收藏内容 |

3. 用户勾选（多选），设置：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 排序 | Integer | 是 | 默认按使用频次 |
| 标签 | Array[String] | 否 | 用于分类显示 |

4. 用户点击「确认」 → 快捷入口添加到工作台

## 3. 「配置工作台布局」按钮（FR-DASH-001-01）

**触发位置**：工作台右上角「编辑模式」。

**操作流程**：

1. 用户点击「编辑模式」 → 工作台进入可编辑状态（卡片周围出现调整手柄）
2. 用户可执行：

| 操作 | 说明 |
|------|------|
| 拖拽移动 | 调整卡片位置（保存为坐标） |
| 缩放 | 调整卡片大小（1x1 / 2x1 / 2x2） |
| 删除 | 从工作台移除卡片（保留模板中） |
| 添加 | 跳转到指标卡/快捷入口添加流程 |
| 撤销/重做 | 操作历史（最近 20 步） |

3. 用户点击「保存布局」 → 写入 `dashboard_workspace` 表 → 实时同步到其他设备
4. 用户点击「恢复默认」 → 重置为平台默认布局

## 4. 「添加收藏」按钮（FR-DASH-004）

**触发位置**：任意应用/数字员工/文档详情页 → 右上角「收藏」图标。

**操作流程**：

1. 用户点击「收藏」 → 弹出"添加到收藏"对话框
2. 用户选择：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 收藏夹 | Ref | 是 | 默认「默认收藏夹」 |
| 标签 | Array[String] | 否 | - |
| 备注 | Text | 否 | - |

3. 用户点击「确认」 → 写入 `favorite` 表 → 工作台「我的收藏」显示

## 5. 「编辑个人信息」按钮（FR-DASH-005-01）

**触发位置**：工作台右上角头像 → 「个人中心」 → 「编辑资料」。

**操作流程**：

1. 用户点击「编辑资料」 → 进入编辑表单
2. 用户可修改：

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| 头像 | Image | 是 | ≤ 2MB |
| 显示名 | String(2-20) | 是 | - |
| 邮箱 | Email | 是 | 唯一 |
| 手机号 | String | 否 | 11 位 |
| 个人简介 | Text(0-200) | 否 | - |

3. 用户点击「保存」 → 写入 `user_profile` 表 → IAM 同步

## 6. 「修改偏好设置」按钮（FR-DASH-005-02）

**触发位置**：个人中心 → 「偏好设置」。

**操作流程**：

1. 用户点击「偏好设置」 → 进入设置表单
2. 用户可修改：

| 字段 | 类型 | 默认 | 选项 |
|------|------|------|------|
| 语言 | Enum | 跟随浏览器 | zh-CN/en-US/ja-JP |
| 时区 | Enum | 跟随系统 | Asia/Shanghai 等 |
| 日期格式 | Enum | YYYY-MM-DD | YYYY-MM-DD/MM/DD/YYYY/DD/MM/YYYY |
| 主题 | Enum | Dark | Light/Dark/Custom |
| 密度 | Enum | Comfortable | Compact/Comfortable |
| 通知偏好 | JSON | 全开 | 按渠道/事件类型 |

3. 用户点击「保存」 → 实时生效（前端重渲染）

## 6. 「创建 API Token」按钮（FR-DASH-005-05）

**触发位置**：个人中心 → 「API Token」 → 「新建 Token」。

**操作流程**：

1. 用户点击「新建 Token」 → 弹出"创建 API Token"对话框
2. 用户填写：

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| Token 名称 | String(2-30) | 是 | 唯一 |
| 权限范围 | Array[String] | 是 | 至少 1 个 |
| 过期时间 | DateTime | 是 | > 当前时间 |
| IP 白名单 | Array[String] | 否 | - |

3. 用户点击「生成」 → 系统生成 Token（一次性展示）→ 用户必须复制保存
4. 用户点击「我已保存」 → Token 写入 `api_token` 表（hash 存储）

## 7. 「订阅通知」按钮（FR-DASH-003-02）

**触发位置**：通知中心 → 「订阅设置」。

**操作流程**：

1. 用户点击「订阅设置」 → 进入配置面板
2. 用户配置：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 事件类型 | Multi | 是 | 系统/审批/AI/数字员工/工单 |
| 渠道 | Multi | 是 | 站内/邮件/IM/SMS |
| 优先级过滤 | Enum | 是 | 全部/高+紧急/仅紧急 |
| 时间窗口 | Cron | 否 | 工作时间/全部时间 |

3. 用户点击「保存订阅」 → 写入 `notification_subscription` 表

## 8. 「编辑待办」按钮（FR-DASH-001-02）

**触发位置**：工作台待办卡片 → 单个待办「操作」菜单。

**操作流程**：

1. 用户点击「操作」 → 弹出操作菜单：

| 操作 | 行为 |
|------|------|
| 标记已读 | 待办状态 → COMPLETED |
| 标记过期 | 标记为已过期（保留记录） |
| 重新分配 | 改派给其他用户 |
| 添加备注 | 增加处理备注 |
| 查看源 | 跳转到源对象（工单/审批） |

2. 用户点击「标记已读」 → Toast 提示「已处理」 → 待办卡片移除

## 9. 「自定义门户」按钮（FR-DASH-001-09）

**触发位置**：门户页 → 「自定义门户」。

**操作流程**：

1. 用户点击「自定义门户」 → 进入门户编辑器
2. 用户从左侧组件库拖入：

| 组件类型 | 说明 |
|---------|------|
| 指标卡 | 同 §1 |
| 应用列表 | 用户收藏的应用 |
| 数字员工列表 | 活跃数字员工 |
| Markdown 文本 | 自定义说明 |
| 链接列表 | 外部链接 |
| 待办列表 | 个人待办 |
| 通知列表 | 未读通知 |

3. 用户拖拽调整布局
4. 用户点击「保存门户」 → 写入 `portal_config` 表

## 10. 「上传头像」按钮（FR-DASH-005-01）

**触发位置**：个人中心 → 头像 → 「更换头像」。

**操作流程**：

1. 用户点击「更换头像」 → 弹出"上传头像"对话框
2. 用户上传图片（支持 JPG/PNG/WEBP，≤ 2MB）
3. 系统自动裁剪为正方形（中心点对齐）
4. 用户可拖动调整裁剪框
5. 用户点击「确认」 → 上传到 TECH-DATA → 写入 `user_profile.avatar`
