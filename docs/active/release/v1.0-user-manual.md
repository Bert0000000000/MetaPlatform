# Mate Platform 用户手册（v1.0）

> 版本: v1.0 · 日期: 2026-09-09 · 配套: `v1.0-release-notes.md` / `v1.0-known-limitations.md`

## 1. 快速开始

1. 打开平台入口 `http://localhost:9250`（部署见运维手册）。
2. 使用账号登录（默认管理员 `admin`，密码由部署方提供；登录走 Keycloak
   OIDC，签发 RS256 JWT）。
3. 登录后进入**工作台**：应用、消息、通知与待办集中在左栏导航。

## 2. 核心功能

### 2.1 SuperAI（AI 对话与调度）
- 路径 `/superai/chat`。输入问题即触发「RAG 检索 + LLM 生成」；回答可附
  资料引用卡片。
- Agent 调度：开启「Agent 调度」后，LLM 通过 function-call 决策调度数字
  员工（角色来自授权快照），过程实时可见（思考/工具调用/结果事件）。
- 语义路由：每次请求产生 `routing_decision` 审计（可在架构中心追溯）。

### 2.2 本体引擎（Ontology Studio）
- 路径 `/ontology`。概念模型/关系类型/动作类型/数据中心/知识图谱分页。
- 建模：**新建概念** → 定义属性（主键、类型、可空）→ 保存（AI 提议会先
  生成 proposal，确认后才落库）。
- 实例：数据中心页按类型录入实例；写回受一致性校验（PK 必填/租户一致）。
- 去重：创建前 precheck 返回相似候选；确认后可 merge（可 revert 回滚）。

### 2.3 云市场（Marketplace）
- 路径 `/apps?tab=market`。订阅第三方模板 → install 流程
  （downloading→verifying→installed），支持 retry / uninstall；全部状态
  转移有审计记录（`marketplace_install_audit`）。

### 2.4 知识库（KB/RAG）
- 上传文档后自动分片索引（pgvector + Milvus）；对话中自动引用。

### 2.5 数据产品
- 数据资产目录：`/arch/data/assets`；数据产品以 Iceberg ADS 形式发布
  （modality=structured/…/mixed），lineage/quality/catalog 三面可查。

## 3. 常见问题
- **登录 401**：token 过期（默认 5 分钟刷新），重新登录。
- **403 tenant binding rejected**：请求头租户与账号租户不一致。
- **上传无引用**：索引异步进行，稍候重试。
