## 1. 版本定位

MetaPlatform v1.0 是企业级 AI 平台的**首个正式发布候选**：Ontology 本体引擎 + Polyglot Microservice + 数字员工 + SuperAI 编排平面的结构性能力全部落地，真实准生产链路（真实 LLM、真实多模态、17 域 e2e 全通、路由审计落库）已在本版本内收口。

**一句话**：从「结构性测试通过」推进到「真实准生产 · 端到端验收」的 v1.0。

## 2. 核心亮点

### 2.1 Ontology 内核与语义层

- **12 Kernel 基元**（ADR-0021 冻结）：ClassRef / Version / Property / ObjectType / LinkType / ActionType / Interface / Individual / LinkInstance / Axiom / Function / ObjectSet，`rid` 全局可追溯。
- **PG 全量持久化**：本体类型/实例/Link/Axiom/Function 全部落 PostgreSQL；12/12 基元 PG 路径逐项验收（ONT-G6）。
- **本体验证与推理**：ONT-G17 validation 8/8、ONT-G18 Axiom 注册中心（CRUD + derivation chain + explain 3 链）、G16/G13 推理、G8/G19 版本化、G9/G20 互操作均 Accepted（详见 `evidence/ONT-*-ACCEPTANCE.md`）。
- **数据迁移生产门**（ONT-G3/G5）：seed→备份→迁移→字段级比对→回滚→再迁移全链 PASS；export bundle→DELETE→import→GET 200 演练 + runbook（`runbooks/ont-promotion-gate.md`）。
- **性能基线**（ONT-G4）：10k 实例 + composite 索引，ObjectSet 查询 P50=25.0ms / P95=27.6ms。

### 2.2 SuperAI 编排平面（copilot agent loop）

- **LLM 决策 → 数字员工调度 → 结果回填**的完整 agent loop；MiniMax/GLM 等真实 provider 流式 reasoning（单轮最高 873 个 reasoning 事件）+ 并行 dispatch + 降级链（semantic_router → embedding → keyword）。
- **语义路由可审计**（本批收口）：`routing_decision`（pre_screen + final 双阶段）→ `copilot.routing.decided` outbox 事件 → PG `outbox_event` 表持久化；writer 缺失时 fail-closed（`routing_audit_unavailable`），配套 12 个审计回归测试。
- **工具注册表面向调用方开放**（本批新增）：`GET /api/v1/copilot/agent-tools` 返回 agent loop 的实时工具集（dispatch_employee 枚举限定授权角色 + 32 个本体工具），双源（orchestrator/ontology）独立降级可见。
- **fail-closed 授权**：未授权目标（如未在授权候选集的数字员工）被 LLM 正确拒绝并解释，不静默派发。

### 2.3 LLM Gateway（llmgw）

- **Provider 路由修复 + 请求级覆盖**：`OPENAI_BASE_URL` env 消费 + ChatRequest `base_url/api_key` 请求级覆盖；Agent 决策（带 tools 的请求）永不合成兜底回复（fail-closed）。
- **多模态 live 收口**（本批）：`POST /api/v1/llmgw/chat/multimodal` 接入真实 OpenAI 兼容 vision provider；live 证据：图片（红色圆形 + 蓝色方块）→ GLM-5.3-flash（ARK Plan）正确描述形状/颜色/方位（280 tokens）。provider 解析：请求覆盖 > env > dev stub；生产 profile 禁 stub。
- **后台 Provider 配置**：用户在平台后台配置 ARK Plan custom provider（`/api/plan/v3` + GLM-5.3-flash，default_active=custom），copilot/llmgw 全链消费。

### 2.4 集成与协议

- **MCP / A2A 协议中心**：官方 SDK + 自建加固；W3C A2A 消息/任务模型（`/messages`、`/execute`、Task 状态机）；mcp federation 单 server live（ont_list_classes tool_call 200）。
- **17 域全链路 e2e 26/26 PASS**（本批修零）：ont/llmgw/mcp/copilot/arch/apphub/orchestrator/auth/agent/rag/dw/msg/kb/data/etl/scheduler/metrics/a2a 直连探活 + temporal gRPC + 7 个网关业务 API（含新增 copilot agent-tools）。脚本 `mate-platform-backend/scripts/e2e_17_domains.py`。
- **平台探活惯例统一**（本批）：a2a 补齐 `GET /healthz`（与其他 13 域对齐，匿名探活）。
- **组合内核**（MP-COMP-01 / ADR-0042/43）：`mate_platform/composition` 落地，能力反应式可用性即 Marketplace 订阅语义。

### 2.5 数字员工与 Marketplace

- **7+1 类数字员工**（Ontology/Workflow/App/Data Product/OBS/Security/Knowledge Library + SuperAI）+ 7+N Marketplace 订阅模型。
- **MARKETPLACE-CONSUMER-01** 收口：install 事务化 + 审计 + 消费面（SessionEvolution.mount / CapabilityRuntime）连通。
- **MP-SAL 程序 6/6**（01-05 + 04B）：Agent 直查本体（虚拟工具注册表）、OAG 对象卡片注入 prompt、结构化 ObjectQuery IR、semantic_router 语义预筛。

### 2.6 平台工程与治理

- **13 条硬规则**全部有可执行门禁（pre-commit + CI jobs + 测试三层）；本批两处新路由（copilot agent-tools、llmgw multimodal 字段）均先更新 OpenAPI 契约再实现。
- **安全基线**：Keycloak JWT + 服务身份（SEC-IAM-01）+ 5 层租户隔离（SEC-TENANT-01，12 个跨租户 negative 测试）+ K8s/NetworkPolicy/Helm（PLATFORM-K8S-01）。
- **可观测**：OTel 全链路（trace/metrics/log）、copilot.invoke journey span、outbox 事件审计。
- **事件架构**：Outbox + 幂等消费者 + DLQ（PLATFORM-EVENT-01）；路由审计复用同一 outbox。
