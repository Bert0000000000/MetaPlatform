# 官网入口与本体操作修复

2026-10-13，范围由用户授权：官网介绍 → 平台登录、新建本体、相关细粒度操作、图谱布局；验证后合并 main 并部署腾讯云演示环境。

## 已复现的问题

- 当前云端与 main 为 `34420e2699bf823f7ea35e73120b85d7f97ac629`。公网 `/` 直接进入登录页，已有 `/website/` 介绍页与 `/home` 平台入口。
- 公网 HTTP 登录后，从模型工作台点击“新建资源”，页面显示 `crypto.randomUUID is not a function`。属性草稿、关联对象、提案确认/执行/拒绝、分析固定卡片也存在相同调用。
- 图谱内容容器与 SVG 各自使用固定高度，底部筛选和检查区被裁切；可用空间变化时无法完整铺满工作区。
- 模型关系图的连线没有接入关系选择回调，点击或键盘选择后无法查看关系定义。

## 修复边界

- 复用已有官网与认证入口，根访问先展示官网；平台深链继续走既有登录守卫。
- 统一 UUID v4 生成：优先浏览器原生方法，HTTP 环境使用 `crypto.getRandomValues`。保持模型 RID、租户、幂等与发布契约不变。
- 创建/编辑、属性增删与嵌套字段、关联、提案操作在 HTTP 能力条件下验证；现有草稿、冲突、确认与输入保留行为继续回归。
- 图谱使用可用空间，侧栏独立滚动；核对搜索、选择、缩放、适应、布局恢复、展开、列表与小屏幕显示。
- 沿用 ADR-0069（本体导航）、ADR-0080（草稿与版本）、ADR-0082（迁移）及 `ont.yaml`；本轮不新增 API。
