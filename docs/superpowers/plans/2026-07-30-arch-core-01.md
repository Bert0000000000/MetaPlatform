**Goal:** 建立唯一架构底座 `mate-kernel` / `mate-platform` / `mate-clients`，强制四层模块边界，禁止生产装配 fake adapter，并把 Ruff/Pyright 纳入 CI 强制门禁。

**Architecture:** 现有 Python 后端由若干 `mate-tech-*` / `mate-app-*` 包组成，但没有共享内核和 ACL Client 库；`domain` 与 `infrastructure` 互相耦合。ARCH-CORE-01 不动业务逻辑，引入三个内核包并以 architecture tests 和 import-linter 约束依赖方向，同时消除根目录重复的部署源码。

**Tech Stack:** Python 3.12、SQLAlchemy 2 / SQLModel、Pydantic v2、FastAPI、httpx、import-linter、Ruff、Pyright、pytest、PyYAML。
