# 逆向继承实例关联修复

依据：用户授权核对平台能力后修复；[ADR-0083](../../active/decisions/ADR-0083-data-driven-modeling-phase1.md)、[原生继承关系计划](2026-10-13-inherited-relationships.md)。

复现：植物标本父类声明采样点、调查批次两条关系，18 个实例只映射到三个子类；旧编译器关系数为 0，且零警告。原生关系写入已支持合法后代，缺口在逆向编译。

方案：经过结构校验的候选单继承链计算自身和祖先索引，自动关联将实例索引到自身与每个祖先端点；人工连线按同一祖先集合检查。原节点、最具体类、身份及关系定义不变；保留完整来源编译、范围/排除、基数与容量限制。API 请求/响应及原生契约不变，无数据库迁移或前端样式调整。

1. 红测试：来源/目标多级继承、直接类与兄弟、匹配率和缺失目标、人工增删、不合法端点、合格子集隔离、基数与容量。
2. 实现编译端点继承，运行建模相关回归。
3. 独立 PostgreSQL 验证新建、复用、重复同步及两端后代 RID；强制六组门禁实际执行。
4. 独立浏览器使用植物样本的固定已审核候选，从发布到同步回读 24 个实际对象与 36 条关系；源 AI 结果不重新随机生成。
5. 记录结果与证据；不触碰已有配置、其他在途修改、业务数据库或现存工作树。
