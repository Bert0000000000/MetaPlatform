# 候选关系可操作性修复

状态：已实施、本地验证通过并加载运行服务；详见[验收记录](../../acceptance/2026-10-11-relationship-readiness.md)。

依据 ADR-0083，保留人工确认业务基数、身份和替代唯一键的原则。生成阶段提前记录关系字段缺失；审核阶段显示目标身份及缺项，精确且无歧义的同名/同 ID 属性提供待确认映射建议，不自动改变身份、基数或发布范围。没有足够来源字段时提供目标身份编辑与暂缓关系入口。

字段下拉框明确区分未选择和有效选择；不完整关系不能显示为已确认或被批量确认。修改映射建议后退回待审核。关联来源列证据与实际 joins 配置分开展示，样本唯一性不作为业务确认。

不新增 API 或改变实例写入流程；不修改用户现有草稿。验证覆盖复合身份缺失、同名属性歧义、显式采用建议、暂缓及后端生成预检。
